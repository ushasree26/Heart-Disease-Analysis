❤️ Heart Disease Analytics Dashboard Using Tableau
📌 Project Overview

This project focuses on analyzing heart disease data using SQL and Tableau to uncover meaningful health patterns and risk factors. The objective is to transform structured healthcare data into interactive dashboards and stories that provide clear, visual insights into cardiovascular risk indicators.

The final dashboards and Tableau stories are embedded into a Flask-based web application, enabling users to access and explore the analysis online.

🎯 Project Objectives

Analyze heart disease data stored in MySQL

Identify key risk factors such as age, gender, diabetes, smoking, BMI, and physical activity

Develop interactive dashboards for comparative health analysis

Present insights using Tableau Story for structured storytelling

Deploy dashboards through a Flask web interface

🛠 Technologies Used

MySQL (Data Storage & Querying)

SQL (Data Processing & Filtering)

Tableau (Data Visualization & Storytelling)

Flask (Web Integration)

HTML / CSS (Frontend Design)

Tableau Public (Publishing & Sharing)

📊 Dashboard Components

The dashboard includes detailed visual analysis of:

Gender vs Heart Disease

Age vs Heart Disease

Diabetes vs Stroke

Smoking & Alcohol Impact on Heart Disease

Race-wise Heart Disease Distribution

General Health vs Heart Disease

Physical Activity vs Heart Disease

Age, BMI & Diabetic Analysis

Stroke Cases with Diabetes & Heart Disease

Each visualization contributes to identifying high-risk groups and lifestyle-related health trends.

📖 Story-Driven Analytical Flow

The Tableau Story presents the analysis as a structured visual journey:

📌 Overview of heart disease prevalence
📊 Demographic comparison (Age & Gender)
⚠ Lifestyle risk factor analysis (Smoking, Physical Activity)
🩺 Medical condition correlation (Diabetes & Stroke)
📈 Population health comparison (Race & General Health)
❤️ Identification of high-risk segments
